### 카카오 링크 구조 (중요)
카카오톡 API는 **카카오 앱에 등록한 도메인만** 메시지 링크로 열 수 있습니다(최대 10개).
매일 바뀌는 수십 개 언론사 주소를 모두 등록할 수 없으므로, 각 기사 항목은
`https://아이디.github.io/hisco-news/go.html?id=…` (우리 뉴스판의 이동 페이지)로 연결하고,
이 페이지가 원문 상태를 확인한 뒤 **즉시 원본 언론사 URL로 이동**합니다.
Google News 같은 외부 중계 페이지는 거치지 않습니다. 원문이 삭제·이동된 것으로 점검되면
자동 이동하지 않고 경고와 함께 '같은 사건 다른 출처'로 안내합니다.

## 2. 설치 (처음 1회, 약 40분)

> 카카오·GitHub 화면의 메뉴 이름은 개편에 따라 조금씩 다를 수 있습니다.

### 2-1. GitHub 저장소 만들기
1. github.com 가입·로그인 → 오른쪽 위 **+ → New repository**
2. 이름 `hisco-news`, **Public** 선택 (Pages 무료 사용 조건. 뉴스판도 공개되나 뉴스 링크만 담기며 검색엔진 노출은 막아 둠)
3. 이 폴더의 파일 전체를 업로드 (**Add file → Upload files**, `.github` 폴더 포함)
   - `.github` 폴더가 업로드 화면에서 안 보이면 GitHub Desktop 사용을 권장합니다.
4. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `/docs` → Save
5. **Settings → Actions → General** → Workflow permissions: **Read and write permissions** → Save

뉴스판 주소: `https://아이디.github.io/hisco-news/` (아이디는 소문자)

### 2-2. 카카오 개발자 앱 만들기
1. developers.kakao.com 로그인 → **내 애플리케이션 → 애플리케이션 추가** (이름: HISCO 뉴스)
2. **REST API 키**와 **클라이언트 시크릿** 값을 메모 (시크릿은 기본 활성화 상태)
3. **웹 도메인(플랫폼/제품 링크 관리)** 에 `https://아이디.github.io` 등록
4. **카카오 로그인** 활성화 → **Redirect URI** 에 `https://아이디.github.io/hisco-news/kakao_callback.html` 등록
5. **동의항목** → '카카오톡 메시지 전송(talk_message)' 사용 설정

### 2-3. GitHub 토큰(GH_PAT) 만들기 — 카카오 인증 자동 연장용
카카오 인증(refresh token)은 약 2개월마다 새로 발급되며, 이를 자동 저장하려면 토큰이 필요합니다.
1. GitHub **Settings(개인) → Developer settings → Fine-grained tokens → Generate new token**
2. Repository access: *Only select repositories* → `hisco-news`
3. Permissions → Repository → **Secrets: Read and write**
4. 만료일은 최대로(예: 1년) 설정하고 달력에 갱신일 기록

### 2-4. 비밀값(Secrets) 등록
저장소 **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 | 필수 |
|---|---|---|
| `KAKAO_REST_KEY` | 카카오 REST API 키 | 필수 |
| `KAKAO_CLIENT_SECRET` | 카카오 클라이언트 시크릿 | 필수(시크릿 사용 시) |
| `GH_PAT` | 2-3에서 만든 토큰 | 필수 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 네이버 개발자센터 '검색' API 키 | **강력 권장** — 원본 URL을 직접 주어 원문 확보율이 가장 높음 |
| `ANTHROPIC_API_KEY` | Claude API 키 | 선택 — 넣으면 'AI 요약' 칸 생성(소액 과금), 없으면 원문 발췌만 표시 |

### 2-5. 카카오 연결 (최초 인증)
1. 저장소 **Actions → 카카오 최초 인증 → Run workflow** (code 비워 두고 실행)
2. 실행 기록의 `auth-url` 단계를 열면 카카오 인증 주소가 나옵니다 → 그 주소를 열어 카카오 로그인·동의
3. 이동한 페이지에 표시된 **인증 코드** 복사 (10분 안에, 1회용)
4. 다시 **카카오 최초 인증 → Run workflow**, code 칸에 붙여 넣고 실행
5. 카카오톡 '나와의 채팅'에 **연결 완료** 메시지가 오면 성공

### 2-6. 시험 실행 → 실제 원문 링크 점검
1. **Actions → 매일 계측뉴스 발송 → Run workflow → "점검만 (카카오 발송 안 함)"**
2. 끝나면 실행 화면 **Summary** 에 **원문 링크 점검 보고서**가 나옵니다
   (Google News 원본 URL 해석 성공 건수, 링크 상태별 건수, 추천 10건의 HTTP 응답·제목 일치·원문 URL, 열리지 않은 링크 목록)
3. 뉴스판 주소를 열어 제목을 눌러 원문이 열리는지 확인
4. 이상 없으면 **"지금 바로 발송"** 으로 카카오톡 수신 확인
5. 다음 날부터 매일 오전 8시 자동 발송

## 3. 운영

### 링크 상태의 뜻
| 상태 | 뜻 | 추천 |
|---|---|---|
| 정상 | 원문 페이지가 열리고 제목이 일치 | ○ |
| 이동됨 | 원문 주소가 홈페이지 등 다른 곳으로 넘어감(삭제 의심) | × |
| 삭제됨 | 404/410 또는 '없는 기사'·빈 페이지 | × |
| 자동확인불가 | 언론사가 자동 점검을 차단(403 등) — 브라우저에서는 열릴 수 있음 | × |
| 접속오류 | 시간 초과·접속 실패 | × |
| 중계 링크 | 원본 URL을 확보하지 못함 | × |

### 자주 바꾸는 설정 — `config.yaml`
- `keywords`: 검색 키워드와 가중치
- `official`: 경쟁사 보도자료 목록 주소 (첫 점검 보고서에서 **수집 0건**인 회사는 주소·선택자를 확인)
- `exclude_publishers`: 추천에서 뺄 출처 (홍보성 시장보고서 사이트 등)
- `preferred_publishers`: 같은 사건일 때 대표 기사로 우선할 언론사
- `top_n`, `send_at`: 발송 건수·시각

### 문제 해결
| 증상 | 확인 |
|---|---|
| 카카오톡이 안 옴 | Actions 실행 기록의 오류 메시지. '토큰 갱신 실패'면 2-5 최초 인증 다시 실행 |
| '카카오 인증 만료 예정' 알림 | GH_PAT 만료 여부 확인 후 2-5 다시 실행 |
| 메시지는 오는데 눌러도 안 열림 | 카카오 앱 웹 도메인에 `https://아이디.github.io` 등록 여부 |
| 8시보다 늦게 옴 | GitHub 예약 실행이 혼잡 시간에 지연될 수 있음(보통 수 분) |
| 원문 확보율이 낮음 | 네이버 API 키 등록 (Google News 해석은 Google 측 변경 시 실패할 수 있음 — 실패해도 '중계 링크'로 표시되고 추천에서 빠질 뿐 잘못된 주소를 만들지 않음) |
| 60일 넘게 실행이 멈춤 | GitHub는 활동 없는 저장소의 예약 실행을 멈춤 — 매일 자동 커밋으로 유지되나, 멈추면 Actions에서 Enable |

## 5. 개발 시 시험 결과 (2026-10-13)

- 단위 테스트 29건 통과 (가상 주소 사용)
- **실제 Google News 기사 8건 → 원본 언론사 URL 해석 8/8 성공**, 그중 원문 3건(데일리시큐·에이빙·한국데이터경제신문)이 실제로 열리고 제목 일치 확인
- 실제 테스트에서 발견해 고친 결함
  1. Google 응답의 `=`(=) 이스케이프로 원문 주소가 `?idxno`에서 잘리는 문제 → 추측성 추출 제거, 정식 해석만 사용
  2. 없는 기사 번호에 '정상 응답 + 빈 페이지'를 주는 언론사 → 빈 페이지를 '삭제됨'으로 판정
  3. 같은 사건인데 제목 표현이 달라 묶이지 않던 문제 → 회사명 등 고유어 공유 기준 추가
  4. 무관 기사(항공사 팝업 등)·홍보성 시장보고서 사이트 유입 → 관련성 필터·출처 제외 설정
- 이 개발 환경에서 직접 확인하지 못한 것: 실제 카카오톡 발송, GitHub Actions 실행, 네이버 API, 경쟁사 보도자료 페이지 선택자 → 2-5·2-6 단계 실행으로 확인
